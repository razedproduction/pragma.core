# Решения проекта pragma.core

ADR-лог. Решение меняется только новой записью с причиной (старую не удаляем, помечаем «заменено #N»).

| # | Решение | Выбор | Почему | Дата |
|---|---------|-------|--------|------|
| 1 | Границы ядра | Runtime-ядро: base + sync + jobs + граф кадра + async. **Без** ECS, рендера, окна, App/плагинов | Ядро должно годиться для разных движков и фреймворков; ECS и цикл кадра — решения конкретного движка, строятся поверх | 2026-10-13 |
| 2 | Платформы | Windows и Linux (x86_64), обе в CI | Текущие цели. macOS/wasm/мобильные вне скоупа; API не должен исключать однопоточный fallback (нужен для wasm без atomics), но и не реализует его | 2026-10-13 |
| 3 | Аудитория | Свои инди-проекты с заделом на профессиональное использование | Простой API сейчас; «профи»-гарантии (детерминизм, semver-checks, бенч-гейт, MSRV) вводятся поэтапно и обязательны к v1.0 — см. roadmap | 2026-10-13 |
| 4 | Чистота зависимостей | Только pure Rust; системные FFI (`windows-sys`, `libc`) допустимы | Воспроизводимая сборка, кросс-компиляция, аудит. Проверка: `cargo deny`, `tools/audit_workspace.py` | 2026-10-13 |
| 5 | Lock-free основа | `crossbeam-deque` / `crossbeam-utils` вместо своих lock-free структур | Проверенный годами pure-Rust код; собственный Chase-Lev deque — месяцы верификации ради единиц процентов | 2026-10-13 |
| 6 | Политика `unsafe` | `#![forbid(unsafe_code)]` везде, кроме `pragma_sync`; там — `// SAFETY:` на каждый блок, Miri + loom в CI | Локализует риск в одном маленьком крейте, который реально можно проверить | 2026-10-13 |
| 7 | Исключение чистоты | `generator` (тянет `cc`) через `loom` — принят (уточнено #12) | Только dev-зависимость под `cfg(loom)`, в бинарники пользователей не попадает; `deny.toml` исключает dev-граф | 2026-10-13 |
| 8 | Async-исполнитель | `async-task` + `futures-lite`, без tokio | Ядру нужен исполнитель, а не сетевой реактор; tokio — второй пул потоков и тяжёлые зависимости. Выбор I/O-модели — на вехе M3 | 2026-10-13 |
| 9 | Паники в задачах | Перехват `catch_unwind` в воркере, возврат как ошибки из `join`/хэндла | Паника пользовательского кода не убивает воркер и не вешает ожидающих. При `panic = "abort"` процесс падает — это задокументировано | 2026-10-13 |
| 10 | Тулчейн | Edition 2024, MSRV 1.88 (минимум для proptest), закреплён 1.99.0 | Одинаковые результаты clippy локально и в CI; MSRV проверяется отдельным джобом | 2026-10-13 |
| 11 | Язык | README — английский; `docs/`, `DECISIONS.md`, rustdoc — русский | README виден снаружи; внутренняя документация — на рабочем языке автора. Пересмотреть перед публикацией на crates.io | 2026-10-13 |
| 12 | `loom` в `pragma_sync` | `[target.'cfg(loom)'.dependencies]` вместо dev-зависимости; loom-джоб: `cargo test -p pragma_sync --release --lib --tests` | Библиотека сама импортирует модели loom (`src/primitives.rs`), иначе модель-чекер не видит её атомиков. Без `--cfg loom` зависимость не активируется; `deny.toml` проверяет граф только для `x86_64-pc-windows-msvc`/`x86_64-unknown-linux-gnu`, где `cfg(loom)` ложен. Доктесты исключены из loom-прогона: они работают с реальными потоками вне `loom::model` | 2026-10-13 |
| 13 | Ошибки `pragma_jobs` | Два enum: `JobsError` (создание пула) и `JobError` (исход задачи) | Исход задачи нужно клонировать, сравнивать и пересылать между потоками, а `JobsError` несёт `std::io::Error` (не `Clone`). Исключение из правила «один enum на крейт» (`docs/reliability.md` §2) | 2026-10-13 |
| 14 | Эталон в бенчах | `rayon` — только dev-зависимость `pragma_jobs` | Сравнение накладных расходов с индустриальным стандартом (roadmap M1). В граф пользователей не попадает (`deny.toml: exclude-dev`) | 2026-10-13 |
| 15 | `unsafe` для `scope`/`join` | Стирание лайфтайма задач области и задача-в-слоте на стеке (`StackSlot`) — только в `pragma_sync` (`scope.rs`) | `pragma_jobs` остаётся `forbid(unsafe_code)`: ему отдаётся безопасный API, где `scope()` не возвращается, пока не завершены все задачи (паника в ожидании → `abort`). `StackSlot` убирает `Box` из `join`: на системном аллокаторе Windows аллокация (~90 нс) дороже самого `join` | 2026-10-13 |
| 16 | Главный поток в пуле | Внешние слоты: 4 LIFO-очереди, которые поток вне пула занимает на время `scope`/`join`/`JobHandle::join` | Через FIFO-injector помощь в ожидании брала бы самые старые задачи и наращивала стек квадратично (fib(20) переполнял стек в debug). Внешний поток не берёт `Background`, чтобы не застрять в запекании посреди кадра | 2026-10-13 |
| 17 | Исключение чистоты | `alloca` (собирает C через `cc`) через `criterion` 0.8 — принят | Безусловная зависимость `criterion` на Windows/Unix (варьирует стек при замерах), фичей не отключается. Только dev-зависимость бенчей `pragma_jobs`; `deny.toml` исключает dev-граф, `layers.toml` — `[purity.accepted]` | 2026-10-13 |
